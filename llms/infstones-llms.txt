## API Reference
- [eth_subscribe](https://docs.infstones.com/reference/bnb-chain-eth-subscribe.md): Creates a new subscription over particular events. The node will return a subscription id.
- [eth_unsubscribe](https://docs.infstones.com/reference/bnb-chain-eth-unsubscribe.md): Cancel a subscription.
- [eth_accounts](https://docs.infstones.com/reference/bnb-chain-eth-accounts.md): Returns a list of addresses owned by client.
- [eth_blockNumber](https://docs.infstones.com/reference/bnb-chain-eth-blocknumber.md): Returns the hexadecimal number of the most recent block.
- [eth_call](https://docs.infstones.com/reference/bnb-chain-eth-call.md): Executes a new message call immediately without creating a transaction on the blockchain.
- [eth_estimateGas](https://docs.infstones.com/reference/bnb-chain-eth-estimategas.md): Generates and returns an estimate of how much gas is necessary to allow the transaction to complete. The transaction will not be added to the blockchain.
- [eth_gasPrice](https://docs.infstones.com/reference/bnb-chain-eth-gasprice.md): Returns the current price per gas in Wei.
- [eth_getBalance](https://docs.infstones.com/reference/bnb-chain-eth-getbalance.md): Returns the account balance of a given address.
- [eth_getBlockByHash](https://docs.infstones.com/reference/bnb-chain-eth-getblockbyhash.md): Returns information about a block by hash.
- [eth_getBlockByNumber](https://docs.infstones.com/reference/bnb-chain-eth-getblockbynumber.md): Returns information about a block by block number.
- [eth_getBlockTransactionCountByHash](https://docs.infstones.com/reference/bnb-chain-eth-getblocktransactioncountbyhash.md): Returns the number of transactions in the block with the given block hash.
- [eth_getBlockTransactionCountByNumber](https://docs.infstones.com/reference/bnb-chain-eth-getblocktransactioncountbynumber.md): Returns the number of transactions in the block with the given block number.
- [eth_getCode](https://docs.infstones.com/reference/bnb-chain-eth-getcode.md): Returns the compiled smart contract code, if any, at a given address.
- [eth_getFilterChanges](https://docs.infstones.com/reference/bnb-chain-eth-getfilterchanges.md): Polling method for a filter, which returns an array of logs which occurred since last poll.
- [eth_getLogs](https://docs.infstones.com/reference/bnb-chain-eth-getlogs.md): Returns an array of all logs matching a given filter object.
- [eth_getProof](https://docs.infstones.com/reference/bnb-chain-eth-getproof.md): Returns the account and storage values of the specified account including the Merkle-proof.
- [eth_getStorageAt](https://docs.infstones.com/reference/bnb-chain-eth-getstorageat.md): Returns the value from a storage position at a given address.
- [eth_getTransactionByBlockHashAndIndex](https://docs.infstones.com/reference/bnb-chain-eth-gettransactionbyblockhashandindex.md): Returns information about a transaction by block hash and transaction index position.
- [eth_getTransactionByHash](https://docs.infstones.com/reference/bnb-chain-eth-gettransactionbyhash.md): Returns information about a transaction for a given hash.
- [eth_getTransactionCount](https://docs.infstones.com/reference/bnb-chain-eth-gettransactioncount.md): Returns the number of transactions sent from an address.
- [eth_getTransactionReceipt](https://docs.infstones.com/reference/bnb-chain-eth-gettransactionreceipt.md): Returns the receipt of a transaction by transaction hash.
- [eth_getUncleByBlockHashAndIndex](https://docs.infstones.com/reference/bnb-chain-eth-getunclebyblockhashandindex.md): Returns information about the 'Uncle' of a block by hash and the Uncle index position.
- [eth_getUncleByBlockNumberAndIndex](https://docs.infstones.com/reference/bnb-chain-eth-getunclebyblocknumberandindex.md): Returns information about the 'Uncle' of a block by block number and the Uncle index position.
- [eth_getTransactionByBlockNumberAndIndex](https://docs.infstones.com/reference/bnb-chain-eth-gettransactionbyblocknumberandindex.md): Returns information about a transaction by block number and transaction index position.
- [eth_newBlockFilter](https://docs.infstones.com/reference/bnb-chain-eth-newblockfilter.md): Creates a filter in the node, to notify when a new block arrives.
- [eth_newFilter](https://docs.infstones.com/reference/bnb-chain-eth-newfilter.md): Creates a filter object, based on filter options, to notify when the state changes (logs).
- [eth_newPendingTransactionFilter](https://docs.infstones.com/reference/bnb-chain-eth-newpendingtransactionfilter.md): Creates a filter in the node, to notify when new pending transactions arrive.
- [eth_sendRawTransaction](https://docs.infstones.com/reference/bnb-chain-eth-sendrawtransaction.md): Submits a pre-signed transaction for broadcast to the Ethereum network.
- [eth_sendTransaction](https://docs.infstones.com/reference/bnb-chain-eth-sendtransaction.md): Creates new message call transaction or a contract creation, if the data field contains code.
- [eth_syncing](https://docs.infstones.com/reference/bnb-chain-eth-syncing.md): Returns an object with data about the sync status or false.
- [eth_uninstallFilter](https://docs.infstones.com/reference/bnb-chain-eth-uninstallfilter.md): Uninstalls a filter with given ID.
- [net_version](https://docs.infstones.com/reference/bnb-chain-net-version.md): Returns the current network id.
- [net_listening](https://docs.infstones.com/reference/bnb-chain-net-listening.md): Returns boolean if client is actively listening for network connections.
- [web3_clientversion](https://docs.infstones.com/reference/bnb-chain-web3-clientversion.md): Returns the current client version.
- [web3_sha3](https://docs.infstones.com/reference/bnb-chain-web3-sha3.md): Returns Keccak-256 (not the standardized SHA3-256) of the given data.
